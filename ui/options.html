Create Workspace

A workspace is a set of scopes plus the rules that run on the JavaScript of every page inside them.

* matches anything, so *.example.tld covers every subdomain. Every workspace whose scope matches a page receives that page's findings, so overlapping workspaces both fill.

Out of scope: an endpoint matching any of these is ignored — never stored, never counted as new. Matching is case-insensitive and runs against the whole path, so ^/api/internal/ anchors the start, \.map$ the end. A pattern that does not compile is reported below and skipped by the scanner. The box starts empty: Insert Default Rules adds the twelve-rule noise filter (images, stylesheets, fonts, source maps, static bundles, vendor paths).
